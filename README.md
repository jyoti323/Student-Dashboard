# Brightside classroom dashboard

A cheerful, responsive React dashboard for keeping track of a classroom’s scores. Browse the sample learners, add students, update their grades, and keep an eye on class progress.

## Features

- Live class size, pass count, passing rate, and average score summaries.
- Add students with score and name validation.
- Search students by name and sort the list alphabetically or by score.
- Edit scores in place, view an animated score bar, and remove a student.
- Responsive layout, keyboard-friendly controls, and reduced-motion support.

Student records are held in the app’s current session and reset to the sample class when the page is refreshed.

## Get started

Install the dependencies and start the development server:

```sh
npm install
npm start
```

The dashboard opens at [http://localhost:3000](http://localhost:3000).

## Build

```sh
npm run build
```
